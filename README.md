# OpenDesk 📄📊

**OpenDesk** — свободный open-source клон **Word + Excel** на **React + TypeScript + Vite**.
Работает полностью в браузере, без сервера. Данные хранятся в `localStorage`.

![MIT](https://img.shields.io/badge/license-MIT-green) ![React](https://img.shields.io/badge/React-18-blue) ![TS](https://img.shields.io/badge/TypeScript-5-blue) ![Vite](https://img.shields.io/badge/Vite-5-purple)

## ✨ Что умеет v0.4.0 — Word + Excel уровня 2010

### 📝 Word (OpenDesk Writer) — 7 вкладок как в Word 2010
- **Главная:** шрифты (7), кегль 8–48pt, B/I/U/S, верх/низ индексы, цвет + маркер, регистр, стили p/H1-H3/цитата/код, выравнивание L/C/R/J, отступы, интервалы 1.0–2.0, списки, Найти/Заменить со счётчиком
- **Вставка:** таблицы (до 20×10), рисунки (upload + вставка из буфера Ctrl+V), ссылки, линия, надпись, WordArt, буквица, символы Ω (20 шт), сноски, комментарии 💬, номера страниц
- **Разметка:** поля узкие/обычные/широкие, книжная/альбомная, A4/A5/Letter, 1–2 колонки, цвет страницы, подложка (watermark), разрыв страницы, верхний/нижний колонтитулы
- **Ссылки:** автооглавление из H1-H3, подписи, пометка для указателя (`<mark>`) + генерация указателя
- **Рецензирование:** орфография браузера (ru), статистика (слова/символы/страницы), перевод выделенного, примечания, запись исправлений (ins/del) + принять все, защита «только чтение»
- **Вид:** Разметка/Черновик/Структура, линейка, навигация по заголовкам, ¶ знаки, зум 50–200%, fullscreen
- **Файл:** Новый, Открыть `.html/.txt/.docx` (mammoth), Сохранить HTML, Экспорт **DOCX** (стили: шрифт/цвет/кегль, картинки, ссылки, оглавление-полем, колонтитулы Header/Footer, поля/ориентация/размер, **фигуры/SmartArt/диаграммы как PNG**, **сноски как w:footnotes**), TXT, Печать/PDF (@page), свойства, версии (5 автоснимков с восстановлением)
- **Рассылки:** поля `{{Имя}}`, CSV-данные, слияние в письма с разрывами страниц, конверты, наклейки
- **Доп:** титульный лист, фигуры SVG (▢○→★), SmartArt, диаграммы SVG, формулы (дробь/∑/√/∫), закладки, скриншот экрана, переносы, номера строк, разделы, тезаурус офлайн, сравнение документов
- **Мобильная вёрстка:** лента со скроллом, кнопки 44px, шрифт ввода 16px (без зума iOS), навигация-бургер ☰, страница в 1 колонку, SmartArt вертикально, таблицы Excel 44px строки

### 📊 Excel (OpenDesk Sheets) — 6 вкладок как в Excel 2010
- **Движок:** числа/строки/логика, `+ - * / % ^ &`, сравнения, `$A$1`, `Лист2!A1`, диапазоны, `,`/`;`, **~45 функций EN+RU** (ЕСЛИ, СУММЕСЛИ, СЧЁТЕСЛИ, ВПР, ИНДЕКС, ПОИСКПОЗ, ТЕКСТ, даты-сериалы), ошибки `#DIV/0!/#VALUE!/#REF!/#NAME?/#N/A/#NUM!/#CYCLE!`
- **Листы:** несколько, переименование, `Лист2!A1` в формулах, вкладки
- **Файл:** XLSX экспорт/импорт (стили, объединения, примечания, проверки, даты) + CSV, версии (5 снимков)
- **Главная:** B/I/U, шрифт/кегль/цвет/заливка, выравнивание, границы, форматы (число/₽/%/дата), объединение, Σ Автосумма, сортировка, вставка/удаление строк-столбцов со сдвигом ссылок, Найти/Заменить
- **Вставка:** спарклайны (линия/столбцы/win-loss), диаграммы (бары/линия/круговая), примечания, проверки (списки/диапазоны), УФ (шкалы/бары/значки/условия)
- **Данные:** автофильтр + срезы-кнопки, сводные таблицы на новом листе, текст-по-столбцам, удаление дубликатов
- **Вид:** закрепление строк/столбцов, сетка/заголовки, масштаб, печать (альбомная A4)
- **Сетка 500×52** (A–AZ) с догрузкой, закрепы через sticky, мобильные 44px
- **Тесты:** 26 Excel-тестов (`vitest`)

## 🚀 Быстрый старт

```bash
git clone https://github.com/<твой-логин>/OpenDesk.git
cd OpenDesk
npm install
npm run dev      # http://localhost:5173
npm test         # 37 тестов (Word 11 + Excel 26)
npm run build    # production в dist/
```

Требуется **Node.js ≥ 18**.

## 🌐 Публикация (в т.ч. GitHub Pages)

Проект — 100% статика (React SPA, данные в `localStorage`), собирается в `dist/` и работает везде: GitHub Pages, Netlify, Vercel, Nginx, хоть `file://`.

**Вариант A — автоматически (workflow уже в репо):**
1. Запушь код на GitHub: `git remote add origin https://github.com/<твой-логин>/OpenDesk.git` → `git push -u origin master`
2. В repo → Settings → Pages → Source: **GitHub Actions**
3. Готово: каждый push в `master` сам собирает и деплоит (`.github/workflows/pages.yml`)

**Вариант B — вручную:** `npm run build` → залей содержимое `dist/` на любой хостинг.

Нюансы уже учтены: `base: './'` (относительные пути — работает и в подпапке `/OpenDesk/`, и на своём домене), `public/.nojekyll` (Pages не трогает ассеты), чанки `vendor-react/vendor-docx/vendor-exceljs` для кэширования.

## 📁 Структура

```
OpenDesk/
  src/
    App.tsx            # табы Word / Excel
    word/
      WordEditor.tsx   # лента 7 вкладок Word 2010
      document.ts      # экспорт + подсчёт слов
      docx.ts          # .docx экспорт (docx: PNG-растер SVG, w:footnotes) / импорт (mammoth)
      format.ts        # exec-хелперы, таблицы, оглавление
      word.test.ts     # 11 тестов: слияние, тезаурус, diff, вставки
    excel/
      ExcelGrid.tsx    # лента 6 вкладок, листы, сетка 500×52
      formula.ts       # движок: парсер, 45 функций, даты, сдвиг ссылок
      format.ts        # стили, форматы чисел, УФ-оценка
      logic.ts         # сортировка, сводные, вставка/удаление, проверки
      xlsx.ts          # XLSX экспорт/импорт (exceljs)
      Sparkline.tsx    # спарклайны SVG
      ChartView.tsx    # диаграммы SVG
      *.test.ts        # 26 тестов: движок, логика, XLSX round-trip
  index.html
  vite.config.ts
  package.json
```
